# Несущая плата (carrier board)

**Статус:** accepted
**Связанные:** [ADR-0001](../decisions/ADR-0001-carrier-board-for-atx.md), [ADR-0018](../decisions/ADR-0018-wrx90e-platform.md), [pcie-topology.md](pcie-topology.md).

Несущая — собственная PCB, на которую через стойки устанавливается
**E-ATX** материнская плата (**референсный модуль**: ASUS Pro WS WRX90E-SAGE SE,
30.5 × 33 см). Вокруг неё на несущей размещается периферия.

**Платформа:** 1× sTR5 (Threadripper PRO 7000/9000 WX), **не 2P**.
7 слотов PCIe 5.0 (6× x16 + 1× x8), BMC AST2600, 2× 10G (Intel X710-AT2).

## Разъёмы внешнего БП (1200 Вт, возможно 1600–2000 Вт)

| Разъём | Назначение | Ток/мощность |
|---|---|---|
| 24-pin ATX | матплата | ~75 Вт |
| 2 × 8-pin CPU (EPS12V) | CPU (Threadripper PRO) | до 350 Вт sustained |
| 2 × 8-pin PCIe power | Alveo ×2 (CPU1), NVMe | до 300 Вт |
| 12VHPWR (600 Вт) | опционально (если GPU) | до 450 Вт |
| 6+2-pin PCIe ×2 | опционально (доп. карты) | до 300 Вт |
| SATA power | **не используется** (SATA — только загрузка/логи) | — |
| Molex / 4-pin | DC-DC, вентиляторы несущей | ~20 Вт |

## Распределение по сокетам (архитектурное решение)

- **CPU0**: CORE (Redis/Raw/TimescaleDB), Dispatcher, API, BMC — система.
- **CPU1**: Alveo ×2 (FPGA-to-FPGA P2P), конвертация протоколов, NVMe (Raw).
- **Причина**: P2P только на одном switch (CPU1), разделение ролей,
  апгрейд без остановки CORE.

## Компоновка: 4U × N юнитов

- **4U** — форм-фактор **каждого** юнита, не общее шасси.
- **База**: концентратор (EPYC 9006 SP8) + PLATE-A/B/C (WRX90E) = 4 юнита × 4U.
- **RAID** — опционально (4U), не суперскорости (переупаковка).
- **Число RAID-массивов** — по требованиям заказчика, не фиксировано.
- **Nomad** — опционально, по требованию заказчика.
- **Преимущества**: независимые вентиляторы, свой БП + горячий резерв,
  ремонт одного юнита, апгрейд без остановки остальных.
- **Райзеры** — составные (Gen5, ≤300 мм, с питанием >75W), тест P2P обязателен.

## Горизонт

- **Продакшн**: 2029 (WRX90E проверен, SP8 зрелый).
- **Демо**: раньше, на эмуляторах (AIG-502, умный дом, каналы).
- **Цель**: прототип/демо для ТОСЭР (ГОК, сортировочный, пиролиз), 10–12 концентраторов, штучно.
