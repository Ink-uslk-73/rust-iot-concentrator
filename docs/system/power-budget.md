# Бюджет внешнего БП 1200 Вт

Внешний БП: **1200 Вт**. Питает несущую, на которой стоит ATX-модуль
(ASUS ProArt X870E-Creator). SATA-рельса **не используется**.

## Почему 1200 Вт

Из manual ASUS (раздел «Power connectors»):

> «If you want to use two or more high-end PCI Express x16 cards, we recommend
> using a PSU with **900W~1200W** power or above to ensure the system stability.»

Мы берём **1200 Вт** (верхняя граница рекомендации), чтобы:
- покрыть **две high-end GPU/FPGA** в слотах PCIEX16(G5)_1 и PCIEX16(G5)_2;
- иметь запас 20–30% на пиковые нагрузки Ryzen 9 (350 Вт short);
- не пересматривать БП при добавлении периферии на несущей.

## Ограничения из manual ASUS

- **Ambient temperature: 10–35 °C** (manual, стр. 106–107). Маркетинг ASUS упоминает
  «24/7 @ 45 °C», но manual гарантирует только 10–35 °C. Работа вне 35 °C —
  **вне гарантии ASUS**, требует собственного thermal margin (см. `cooling.md`).
- **12VHPWR / 6+2-pin PCIe на плате отсутствуют**. Питание слотов PCIe — только
  через 24-pin (до 75 Вт на слот). Для GPU/FPGA с TDP > 75 Вт на **несущей**
  ставим собственные **12VHPWR / 6+2-pin** разъёмы с DC-DC от 12 В БП.

## Раскладка по потребителям (1200 Вт)

| Потребитель | Мощность | Примечание |
|---|---|---|
| CPU (Ryzen 9 9000) | ~250 Вт sustained, до 350 Вт short | manual ASUS: 350 Вт fast, 220 Вт sustained, 165 Вт при 85 °C |
| Матплата + память + M.2 + сеть | ~60 Вт | DDR5 4 × DIMM, 10 GbE + 2.5 GbE + Wi-Fi 7, NVMe |
| Слот PCIEX16(G5)_1 (GPU/FPGA) | до 450 Вт | через 12VHPWR на несущей |
| Слот PCIEX16(G5)_2 (GPU/FPGA) | до 300 Вт | через 6+2-pin на несущей |
| Слот PCIEX16(G4) | до 75 Вт | от 24-pin |
| Периферия несущей (DC-DC, Modbus, watchdog, RTC) | ~20 Вт | 5V/3.3V |
| Вентиляторы (CPU + корпус) | ~20 Вт | зависит от корпуса |
| **Итого (2 GPU + периферия)** | **~1175 Вт** | запас ~2% — **впритык** |
| **Итого (1 GPU + периферия)** | **~875 Вт** | запас ~27% |
| **Итого (без GPU)** | **~400 Вт** | запас ~67% |

## Выводы

- **1200 Вт** покрывает два high-end PCIe x16 (по рекомендации ASUS), но **впритык**
  при двух GPU с TDP 450 + 300 Вт. Если планируются именно такие — рассмотреть 1500 Вт.
- **Одна GPU** — 1200 Вт с большим запасом.
- **Без GPU** — 1200 Вт избыточно, но оставляем как задел.
