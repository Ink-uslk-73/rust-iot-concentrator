# NetworkNode — паттерн (роутеры, свитчи, бриджи, гейтвеи, брандмауэры)

**Статус:** спецификация (P3.33/P3.35).
**Связанные:** [ADR-0004](../decisions/ADR-0004-router-gateway-domains.md), [router-gateway.md](router-gateway.md).

## Идея

Один trait NetworkNode — общее; отличия — в плагинах (оверлей, протоколы), конфиге (TOML), метриках (UI, чек-лист).

## Типы

| Тип | Уровень | Роль | Отличия |
|---|---|---|---|
| Router (real) | L3 | Transit, маршрутизация | Оверлей (WireGuard, IPsec), протоколы |
| Router (soft) | L3 | Программный (FRR, nftables) | Конфиг, оверлей |
| Switch | L2 | VLAN, STP | VLAN, STP |
| Bridge | L2 | Мост | STP, фильтры |
| Gateway | L3+ | TLS/UI, mTLS | mTLS, UI, audit |
| Firewall | L3/L4 | Защита от внешних угроз, правила | Правила, NAT, zones |

## Брандмауэр и маршрутизатор (по сателлиту и один у митрополии)

- **По каждому сателлиту** — свой брандмауэр (правила) + маршрутизатор (L3, transit).
- **Один у митрополии** (концентратор) — общий брандмауэр + маршрутизатор (L3, между сетями).
- **Брандмауэр** — защита от внешних угроз, внутри одного сегмента (правила, NAT, zones).
- **Маршрутизатор** — L3, соединяет разные сети (MAN, сателлиты, митрополия).

## Общее / отличия

- **Общее**: trait NetworkNode { kind(), start(), health_check(), metrics() }.
- **Отличия**: плагины (оверлей, протоколы), конфиг (TOML), метрики (UI, чек-лист).
