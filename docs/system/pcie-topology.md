# PCIe топология

**P2P / ACS / xGMI не входят** — это системотехника концентратора (см. `958ea03`),
не сателлита. SATA **исключён**. Только M.2 NVMe и слоты PCIe.

## Слоты PCIe (для Ryzen 9000/7000)

| Слот | Источник | Режим (9000/7000) | Режим (8000) | Примечание |
|---|---|---|---|---|
| PCIEX16(G5)_1 | CPU | x16 / x8 (при двух слотах) | x8 max | верхний слот |
| PCIEX16(G5)_2 | CPU | x8 / x4 (при M.2_2) | **не поддерживается** | делит полосу с M.2_2 |
| PCIEX16(G4) | X870E chipset | x4 | x4 | от чипсета |

## Bifurcation (Ryzen 9000/7000)

- **x16** — только PCIEX16(G5)_1, второй слот пуст;
- **x8/x8** — PCIEX16(G5)_1 + PCIEX16(G5)_2;
- **x8/x4/x4** — PCIEX16(G5)_1 + PCIEX16(G5)_2 + PCIEX16(G4);
- **при M.2_2 активен**: PCIEX16(G5)_1 = x8, PCIEX16(G5)_2 = x4.

Точная таблица bifurcation: https://www.asus.com/support/FAQ/1037507/

## M.2 (без SATA)

| Слот | Источник | Режим (9000/7000) | Режим (8000) | Тип |
|---|---|---|---|---|
| M.2_1 | CPU | PCIe 5.0 x4 | PCIe 4.0 x4 | 2242/2260/2280 |
| M.2_2 | CPU | PCIe 5.0 x4 | **не поддерживается** | 2242/2260/2280 |
| M.2_3 | X870E | PCIe 4.0 x4 | PCIe 4.0 x4 | 2242/2260/2280 |
| M.2_4 | X870E | PCIe 4.0 x4 | PCIe 4.0 x4 | 2242/2260/2280/22110 |

**Sharing:** PCIEX16(G5)_2 делит полосу с M.2_2. Если M.2_2 используется,
PCIEX16(G5)_1 = x8, PCIEX16(G5)_2 = x4. Если M.2_2 не используется, PCIEX16(G5)_2 = x8.
