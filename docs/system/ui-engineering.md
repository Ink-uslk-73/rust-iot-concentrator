## Роль

Инженер: проектирует, настраивает, диагностирует, оптимизирует. Read-write (конфигурация, диагностика).
Дежурные инженеры работают с логами, телеметрией (read-write для своих задач).

## Что (жизненный цикл)

| Этап | Что |
|---|---|
| Проектирование | Таблицы (VLAN, IP, топология), графики (нагрузка, latency), сценарии |
| Реализация | Конфигурация (TOML, VLAN, NET-VM), диагностика |
| Эксплуатация | Диагностика (alive, health_check, watchdog), логи, телеметрия |
| Оптимизация | Графики (нагрузка, latency), сценарии |

## Где

- UI — CORE (axum + SSE, веб, IPv6 ULA);
- Вкладка — в общем чате ЦУ (см. ui-chat.md).
