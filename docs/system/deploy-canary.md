# Деплой, канарейки, сторож версий (P3.49)

**Статус:** draft (P3.49).
**Связанные:** [network-topology.md](network-topology.md), [satellite-vm.md](satellite-vm.md).

## Принципы

- **Нечётные версии** (v4.1, v4.3, v4.5) — **сырые канарейки** (10% → 30% → 60% → 100%).
- **Чётные версии** (v4.2, v4.4) — **стабильные** (после успешной канарейки).
- **Откат** — обязателен (analysis + rollback при деградации).
- **Сторож версий** — **раз в сутки** (проверка обновлений).
- **Метрики** — технические (200 OK, latency P99) + бизнес (ошибки, drops).

## Канарейка (нечётные версии)

1. **10%** трафика → новая версия (2 мин).
2. **Analysis** (ошибки < 1%, P99 < baseline + 10%).
3. **30%** → analysis.
4. **60%** → analysis.
5. **100%** (stable) — чётная версия.

**Откат**: если analysis failed — вернуть 100% на стабильную (чётную).

## Сторож версий (раз в сутки)

- Cron (systemd timer / cron): `0 3 * * *` (03:00).
- Проверка: `git ls-remote` / GitHub API (latest release).
- Если новая версия (нечётная) — уведомление (Bus diagnostic / UI).
- Если стабильная (чётная) — доступна — уведомление.

## Скрипты (позже)

- `scripts/deploy-canary.sh` — деплой канарейки (10/30/60/100).
- `scripts/version-watch.sh` — сторож версий (раз в сутки).
- `scripts/rollback.sh` — откат на стабильную.
