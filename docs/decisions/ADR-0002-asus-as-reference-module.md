# ADR-0002: ASUS ProArt X870E-Creator как reference module

**Статус:** принято
**Дата:** 2026-10-29

## Контекст

Нужно выбрать ATX-совместимую материнскую плату, которая задаст габариты,
слоты PCIe, питание и периферию для сателлита.

## Решение

Берём **ASUS ProArt X870E-Creator WiFi** как **reference module**:

- AM5, Ryzen 9000/8000/7000;
- 4 × DDR5 DIMM, до **192 GB** (manual), **ECC** UDIMM;
- **2 × PCIe 5.0 x16** (CPU) + 1 × PCIe 4.0 x4 (chipset);
- 4 × M.2 (2 × PCIe 5.0, 2 × PCIe 4.0);
- 10 GbE + 2.5 GbE + Wi-Fi 7;
- ATX 30.5 × 24.4 см;
- ambient **10–35 °C** (manual, стр. 106–107).

## Обоснование

- **ECC** — критично для концентртора (24/7).
- **PCIe 5.0** — задел на FPGA/GPU/AI.
- **10 GbE** — для связи с концентратором.
- **ATX** — стандартные стойки, доступность.

## Что НЕ берём из ASUS

- **P2P/ACS/xGMI** — P2P у концентратора, не у сателлита.
- **SATA** — исключён.
- **12VHPWR/6+2-pin PCIe** — на ASUS **нет**, ставим свои на несущей.

## Последствия

- Ambient 10–35 °C (см. `cooling.md`).
- Для GPU/FPGA с TDP > 75 Вт — 12VHPWR/6+2-pin на несущей.
- БП 1200 Вт (см. `power-budget.md`).
