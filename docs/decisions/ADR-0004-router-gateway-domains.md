# ADR-0004: Программные роутер и шлюз по доменам

**Статус:** принято (PLATE-B — TODO)
**Дата:** 2026-10-29

## Контекст

Три домена: PLATE-A (Hard), PLATE-B (Soft), PLATE-C (Life). Роутер и шлюз —
программные, на доменах. P2P не используется (P2P у концентратора).

## Решение

- **PLATE-A (Hard) = Moxa AIG-502**: Intel i7, Modbus RTU/ASCII/TCP клиент
  (функции 1, 2, 3, 4, 5, 6, 15, 16, 23), до 31 ведомого на порт, edge computing,
  интеграция в облако. Готовое устройство в шасси 4U-19.
- **PLATE-B (Soft)**: **TODO: спецификация не готова.**
- **PLATE-C (Life) = несущая + ATX (ASUS) + FPGA SmartNIC**:
  SmartNIC/AI (FPGA 50 Вт), данные, связь с облаками, шлюз.
  RTC DS3231SN, watchdog CH32V003, power mux (резерв-1/2).

## Обоснование

- **AIG-502** — готовый промышленный edge-компьютер с Modbus, не надо
  разрабатывать свои трансиверы.
- **PLATE-C на ASUS** — ECC DDR5, PCIe 5.0, 10 GbE, FPGA SmartNIC.
- **PLATE-B** — оставляем открытым до появления спецификации.

## Последствия

- **Modbus-трансиверы на несущей не нужны** (AIG-502 делает программно).
- PLATE-B — TODO, архитектура домена не фиксирована.
- Питание: БП 1200 Вт + резерв-1 (шины концентратора) + резерв-2 (UPS), MOSFET power mux.
