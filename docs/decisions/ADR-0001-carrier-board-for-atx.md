# ADR-0001: Несущая плата для ATX-модуля

**Статус:** принято
**Дата:** 2026-10-29

## Контекст

Сателлит PLATE-3 должен разместить вычислительный модуль (ATX-совместимую
материнскую плату) и периферию: разъёмы внешнего БП, DC-DC, Modbus-трансиверы,
watchdog, RTC, разъёмы полевых шин. Готовой платы с нужным набором нет.

## Решение

Делаем **собственную несущую плату (carrier board)**, на которую через стойки
устанавливается стандартная **ATX-совместимая материнская плата** (референс:
ASUS ProArt X870E-Creator WiFi, 30.5 × 24.4 см). Периферия размещается вокруг
неё на несущей.

## Обоснование

- **Модульность**: материнскую плату можно заменить без переделки несущей.
- **Габариты**: ATX 30.5 × 24.4 оставляет место по краям для периферии.
- **Питание**: внешний БП 1200 Вт подключается к несущей, а не к матплате напрямую.
  Это позволяет добавить 12VHPWR/6+2-pin для GPU/FPGA, которых **нет** на ASUS.
- **Промышленная периферия**: Modbus RS-485/232 с развязкой, watchdog, RTC — на несущей,
  независимо от матплаты.

## Что НЕ входит

- **PCIe P2P / ACS / xGMI** — системотехника концентратора (см. `958ea03`).
- **SATA** — исключён, только M.2 NVMe.
