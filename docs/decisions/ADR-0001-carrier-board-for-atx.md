# ADR-0001: Несущая плата для ATX-модуля

**Статус:** принято
**Дата:** 2026-10-29

## Контекст

Сателлит PLATE-3 должен разместить вычислительный модуль (ATX-совместимую
материнскую плату) и периферию: разъёмы внешнего БП, DC-DC, FPGA SmartNIC,
RTC DS3231SN, watchdog CH32V003, power mux. Готовой платы с нужным набором нет.

## Решение

Делаем **собственную несущую плату (carrier board)**, на которую через стойки
устанавливается стандартная **ATX-совместимая материнская плата** (референс:
ASUS ProArt X870E-Creator WiFi, 30.5 × 24.4 см). Периферия размещается вокруг
неё на несущей.

## Домены

- **PLATE-A (Hard) = Moxa AIG-502** — отдельное устройство в шасси 4U-19, не на несущей.
- **PLATE-B (Soft)** — TODO: спецификация не готова.
- **PLATE-C (Life) = несущая + ATX (ASUS) + FPGA SmartNIC** — всё на несущей.

## Обоснование

- **Модульность**: материнскую плату можно заменить без переделки несущей.
- **Габариты**: ATX 30.5 × 24.4 оставляет место по краям для периферии.
- **Питание**: внешний БП 1200 Вт подключается к несущей, а не к матплате напрямую.
  Плюс резерв-1 (шины концентратора) и резерв-2 (UPS) через MOSFET power mux.
- **FPGA SmartNIC** (50 Вт) в PCIEX16(G5)_1, PLATE-C.
- **RTC DS3231SN** (I2C, `dtoverlay=i2c-rtc,ds3231`), **watchdog CH32V003** (GPIO).
- **Modbus-трансиверы не нужны** — AIG-502 (PLATE-A) делает Modbus программно.

## Что НЕ входит

- **PCIe P2P / ACS / xGMI** — системотехника концентратора (см. `958ea03`).
- **SATA** — исключён, только M.2 NVMe.
- **Modbus RS-485/RS-232 трансиверы** — не нужны, всё делает AIG-502.

## Последствия

- Нужна разработка PCB несущей (custom, по слоту шасси 4U-19).
- Внешний БП 1200 Вт (см. `power-budget.md`).
- Гарантия ASUS ограничена ambient 10–35 °C (см. `cooling.md`).
- Резервирование: БП + шины концентратора + UPS, MOSFET power mux.
