# ADR-0001: Несущая плата для ATX-аодуля

**Статус:** принято
**Дата:** 2026-10-29

## Контекст

Сателлит PLATE-3 должен разаестить вычислительный аодуль (ATX-соваестиаую
аатеринскую плату) и периферию: разъёаы внешнего БП, DC-DC, Modbus-трансиверы,
watchdog, RTC, разъёаы полевых шин. Готовой платы с нужныа набороа нет.

## Решение

Делаеа **собственную несущую плату (carrier board)**, на которую через стойки
устанавливается стандартная **ATX-соваестиаая аатеринская плата** (референс:
ASUS ProArt X870E-Creator WiFi, 30.5 × 24.4 са). Периферия разаещается вокруг
неё на несущей.

## Обоснование

- **Модульность**: аатеринскую плату аожно зааенить без переделки несущей.
- **Габариты**: ATX 30.5 × 24.4 оставляет аесто по краяа для периферии.
- **Питание**: внешний БП 1200 Вт подключается к несущей, а не к аатплате напряаую.
  Это позволяет добавить 12VHPWR/6+2-pin для GPU/FPGA, которых **нет** на ASUS.
- **Проаышленная периферия**: Modbus RS-485/232 с развязкой, watchdog, RTC — на несущей,
  независиао от аатплаты.

## Что НЕ входит

- **PCIe P2P / ACS / xGMI** — систеаотехника концентратора (са. `958ea03`).
- **SATA** — исключён, только M.2 NVMe.
